# 🎓 Interactive Student Performance Analytics System

A real-world student analytics application built using
**Python**, **Apache Spark**, **PySpark**, **Spark SQL**,
**Spark RDD**, and **Streamlit**.

---

## 📌 Project Description

This project is a full-featured student performance
analytics system that allows users to:

- Add and store student records persistently
- Search for individual students by ID
- View all student records
- Calculate average marks, grades, and pass/fail status
- Perform class-level analytics
- Analyze attendance and study hours
- Analyze subject-wise performance
- Run Spark SQL queries on student data
- Process data using Spark RDDs
- View an interactive web dashboard built with Streamlit
